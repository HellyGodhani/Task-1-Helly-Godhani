# UX Research Project – Time-Poor Professional Fitness App

## Project Overview

This UX Research project focuses on understanding the challenges faced by busy working professionals who struggle to maintain a fitness routine due to limited time and demanding work schedules.

## Problem Statement

Many fitness applications require long workout sessions, gym access, and complex interfaces that are not suitable for professionals with busy lifestyles.

## Research Goal

To identify user pain points and discover opportunities for designing a simple fitness solution that supports short desk-based workouts.

## Research Methods

* User Persona Creation
* Empathy Mapping
* User Journey Analysis
* Problem Identification

## Key Findings

* Users have limited time for exercise.
* Gym-based solutions are often inaccessible.
* Short 5-minute workouts are more practical.
* Users prefer calm and simple interfaces.
